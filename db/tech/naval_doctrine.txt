# Trench Crusade - Naval Doctrine Tech Tree
# db/tech/naval_doctrine.txt
#
# Three doctrines chosen at submarine tier and locked thereafter.
# Ship tech is SEPARATE — any faction can build any ship.
# Doctrine affects how ships are used, not what ships exist.
#
# Fleet in Being    — shock and awe, blessed/cursed capital ships
# Indirect Approach — submarines, sabotage, escort attacks
# Mystical          — sea creatures, coastal support, tidal warfare
#                     (restricted factions only)
#
# Marid get their own path outside the choice system.
